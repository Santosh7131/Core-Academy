What the app stores

Tutors and students use accounts that a tutor creates. The app asks for no email address and no phone number.

AccountsDisplay name, username, role (tutor or student), a student's class, and a scrambled (hashed) version of the PIN or password. The PIN or password itself is never stored. Also whether the account is switched on, failed login counts, and the time it was last used.
TuitionThe tuition's name, its groups (a class and a subject), who belongs to each group, and the join code.
Tests and resultsQuestions, answer options and right answers, time limits and closing times, and for each student the chosen answers, marks, start and finish times, and flagged questions.
Question papersThe photos or PDF pages a tutor uploads, kept in private storage, and the questions read from them.
PhonesFor each phone that runs the app: its model, Android version, app version, a random install ID and which accounts have used it. Notifications use a push token for the phone.
Sign-in logThe time, the username that was typed, whether the login worked, the install ID and the app version.
Server logError messages with the route, time, account and install ID, counts of requests per day, and a record of each AI call (which task, which model, how many tokens, how long it took) without its content.

The app's own tables do not hold IP addresses. They also hold no email addresses, phone numbers, home addresses, dates of birth, location or advertising IDs.

Outside services

These services handle some of the data. Each has its own privacy terms, which apply to what it receives.

NeonRuns the database, the private file storage and the server code. The database and the storage are in AWS Asia Pacific (Singapore).
Google Gemini APIReceives page images and question text, so it can read pages and check answers.
GroqReceives the same, as a second reader and a second checker.
Google Firebase Cloud MessagingDelivers notifications. It receives the phone's push token and the message, such as a test's name and closing time.
GitHubHosts the app file and the update information. When the app looks for an update, and when this website looks up the latest version, GitHub sees the request, including the IP address.

How the AI is used

Page images and the text of questions go to the AI services above, so they can read a paper and propose answers. A page photo contains whatever is printed on the page, so avoid photographing pages that carry student names.

The app does not add student names or marks to what it sends. There is one exception: when a tutor types a student's name in a script other than English letters, such as Tamil or Hindi, the name is sent to an AI service so it can suggest a username in English letters.

Students and children

Students can be children. A tutor creates each student's account, so the tutor decides who gets one. The app asks a student for no email address, phone number or date of birth, and it blocks screenshots on a student's phone while the student is logged in.

How long it is kept

A login session ends after 120 days without use. A tutor can delete a student from the student's page in the app. That removes the student's login and their test results for good. A student who also studies with another tutor keeps their login and their other results.

This website

No cookies, no analytics and no advertising. Your browser keeps two settings on your own device only: the theme and whether animations play. The fonts are served from this site. The home page asks GitHub for the latest version of the app, so GitHub sees your IP address.
